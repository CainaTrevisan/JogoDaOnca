# Jogo da Onça
Versão digital do jogo de tabuleiro [Jogo da Onça](https://pt.wikipedia.org/wiki/Jogo_da_on%C3%A7a)

Música do [Tallbeard Studios](https://tallbeard.itch.io/)
- Sketchbook 2024-08-01 do FREE Music Loop Bundle

## Build
- Instale a linguagem [odin](https://odin-lang.org/docs/install/)
- Vá até a pasta JogoDaOnca
- Compile com `odin build .`
- Rode o executável `JogoDaOnca`

## Configurações
O jogo pode ser configurado adicionando um arquivo `adugo.cfg` na mesma pasta
com o executável do jogo. As configurações são lidas e afetam o jogo mesmo durante sua execução.
Consulte [adugo.cfg](https://github.com/CainaTrevisan/JogoDaOnca/blob/main/adugo.cfg) para ver as configurações possíveis.

# English
Digital version of the boardgame [Adugo](https://en.wikipedia.org/wiki/Adugo)

Music by [Tallbeard Studios](https://tallbeard.itch.io/)
- Sketchbook 2024-08-01 do FREE Music Loop Bundle

## Build
- Install the [odin language](https://odin-lang.org/docs/install/)
- Go to the directory JogoDaOnca
- Compile with `odin build .`
- Run the executable `JogoDaOnca`

## Configuration
The game can be configured by adding the file `àdugo.cfg` on the same directory
of the executable. Configurations are read and applied even during game execution.
See [adugo.cfg](https://github.com/CainaTrevisan/JogoDaOnca/blob/main/adugo.cfg) for the configuration options.

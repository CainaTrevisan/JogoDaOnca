# Jogo da Onça
Jogo baseado nas regras de um jogo de tabuleiro presente na exposição do [Museu das Culturas Indígenas](https://museudasculturasindigenas.org.br/)

Música do [Tallbeard Studios](https://tallbeard.itch.io/)
- Sketchbook 2024-08-01 do FREE Music Loop Bundle

## Build
- Instale a linguagem [odin](https://odin-lang.org/docs/install/)
- Vá até a pasta JogoDaOnca
- Compile com `odin build .`
- Rode o executável `JogoDaOnca`

# English
Game based on the rules of a board game in the [Museum of Indigenous Cultures](https://museudasculturasindigenas.org.br/en/home/)

Music by [Tallbeard Studios](https://tallbeard.itch.io/)
- Sketchbook 2024-08-01 do FREE Music Loop Bundle

## Build
- Install the [odin language](https://odin-lang.org/docs/install/)
- Go to the directory JogoDaOnca
- Compile with `odin build .`
- Run the executable `JogoDaOnca`

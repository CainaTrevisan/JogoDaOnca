Jogo baseado nas regras de um jogo presente na exposição do Museu das Culturas Indígenas
https://museudasculturasindigenas.org.br/

Música do Tallbeard Studios https://tallbeard.itch.io/
- Sketchbook 2024-08-01 do FREE Music Loop Bundle

# Build
- Instale a linguagem [odin](https://odin-lang.org/docs/install/)
- Compile com `odin build .`
- Rode o executável `JogoDaOnca`
